### 🧭 Engineering Tenets

- **Idempotent Automation**: All scripts and developer tools must be safe to execute multiple times without side effects, state corruption, or configuration drift.
- **Minimal Dependencies & High Cohesion**: Favor clean architecture and standard library capabilities before adopting external abstractions.
- **Disciplined Git Hygiene**: Enforce atomic Conventional Commits, semantic PR gating, and clean squash-and-merge trunk history.
- **Verification First**: Validate functionality through deterministic tests and automated audit checks before considering any work complete.
